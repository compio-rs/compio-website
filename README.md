# Compio Website

## Development

```shell
# Install dependencies
pnpm install

# Start the development server
pnpm dev
```

## Build

```shell
# Build for production
pnpm build
```

## Advanced

```shell
# Preview the production build
pnpm preview

# Lint the code
pnpm lint

# Format the code
pnpm format
```
